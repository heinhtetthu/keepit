# Record Types

## Creating a Record Type

1. Navigate to **Record Types** in the sidebar
2. Click **Create Record Type**
3. Enter name, description, and icon
4. Add fields with types, options, and behavior settings

## Field Types

| Type         | Description              |
|--------------|--------------------------|
| text         | Single-line text         |
| long_text    | Multi-line text          |
| integer      | Whole numbers            |
| decimal      | Decimal numbers          |
| currency     | Monetary values          |
| percentage   | Percentage values        |
| date         | Date only                |
| datetime     | Date and time            |
| boolean      | True/False               |
| email        | Email address            |
| phone        | Phone number             |
| url          | URL link                 |
| select       | Single selection         |
| multi_select | Multiple selections      |

## Field Properties

- **required** - Must have a value
- **unique** - No duplicate values
- **searchable** - Included in search
- **sortable** - Can sort by this field
- **filterable** - Available as filter
- **show_in_list** - Visible in table view
- **show_in_details** - Visible in detail view
- **show_in_reports** - Included in exports
