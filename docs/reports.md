# Reports

## Excel Export

- Human-readable headers
- Formatted dates, currencies, booleans
- Frozen header row
- Auto-sized columns
- Respects current filters

## PDF Reports

- Company/application name
- Report title
- Generated timestamp
- Applied filters
- Summary statistics
- Data table with page numbers

## Custom Reports

1. Go to **Reports**
2. Select a record type
3. Choose format (Excel or PDF)
4. Download
